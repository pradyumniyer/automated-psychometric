# Agent prompts (copy one at a time into a NEW agent chat: Codex or Copilot Agent)

Rules: one prompt per chat unless noted; paste the agent's final report to Claude for review before moving on; push only after approval (agents never push). The standing rules live in `.github/copilot-instructions.md` (and `docs/PROJECT_RULES.md`); every prompt points to that file, which works for Copilot and for Codex. Prompts may be refined after a review. Before each run, check `git status --short` prints nothing so the report's `git diff --stat` shows only the agent's work.

## How to run a prompt (one branch per prompt)
1. `git status --short` must print nothing. Then: `git switch local-first-rebuild`, `git pull`, `git switch -c <short-name>` (for example `t1-codex`).
2. Open a NEW chat in the agent you are using, paste only the code block of the prompt, send. Do not use two agents on the folder at the same time.
3. When it stops: `git status --short` (should print nothing) and `git log --oneline -6`; paste the report to Claude.
4. After approval: `git switch local-first-rebuild`, `git merge --ff-only <short-name>`, `git push`, `git branch -d <short-name>`. If the merge refuses, stop and show Claude.
5. If the work is rejected: `git switch local-first-rebuild`, `git branch -D <short-name>` (this discards everything the agent did on that branch).
6. If `git status --short` shows uncommitted changes after the agent stops, do not switch branches; show Claude the output.

## Which model (Codex, updated 20 Oct 2026)
- GPT-6.1 Sol is not available on the owner's ChatGPT Go account. Work is done with GPT-5.6 Luna at medium reasoning (GPT-6 Luna is the cheaper, newer alternative).
- This model builds well from precise specs but misreads loose ones and sometimes reports a feature as done that is not on screen. UI prompts therefore carry a layout or point to the approved mockup file `docs/mockups/response_scale_card_five_scenarios.html` and RESPONSE_SCALES section 15, and every result is hand-tested with pasted test output.
- Avoid GPT-6 Astra (about five times the price of 6.1 Sol), GPT-6 Sol and the other 5.6 models.

5. "Suggest" builds 3 equal-width contiguous bands over the output's possible range, starting at the lowest possible score and ending at the highest: Sum gives whole numbers (for 5 items scored 1-5: 5-11, 12-18, 19-25); Mean gives limits rounded to 2 decimals (for a 1-5 scale: 1-2.33, 2.33-3.67, 3.67-5).
